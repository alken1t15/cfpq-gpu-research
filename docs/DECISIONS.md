# Решения

## 2026-11-03 — сначала воспроизведение и профиль

Основание: прямой порядок действий преподавателя (§4) и неизвестный стек проекта. Оптимизации выбираем по измерениям, а не по предположению о медленных GPU-операциях.

## 2026-11-03 — контекст хранится в файлах

`AGENTS.md` задаёт правила, `STATE.md` фиксирует факты и следующий шаг, остальные документы содержат требования и протоколы. Это позволяет продолжать работу без истории чата; автоматическая память между чатами не предполагается.

## 2026-11-03 — подготовка без выдуманной сборки

Внешние ресурсы недоступны. Поэтому не выбираем библиотеку, backend, версию CUDA или команду запуска до чтения исходников. Локальная NVIDIA GPU не снимает этот вопрос.

## 2026-11-03 — CPU smoke-test через WSL2

Доступ восстановлен, Linux-стек подтверждён исходниками и CI. Проверена CPU-конфигурация из CI без изменений алгоритма; препятствие — `<format>` в GCC 11.4. Сначала подготовить совместимый toolchain и пройти штатные тесты. CPU fallback cuBool не приравнивать к оптимизированному GraphBLAS baseline.

## 2026-11-03 — совместимый toolchain без правок алгоритма

Используем явно GCC 13.4 в WSL и отдельный каталог сборки. После установки `<format>` больше не блокирует сборку. Штатные тесты и независимые сравнения количеств прошли. Подробные версии runtime сохранены, поскольку PPA обновил зависимости.

## 2026-11-03 — исправить формирование индексированных имён

Воспроизведён контрпример до правки, сохранены входы и ответы. Правка локальна к парсеру, не меняет алгоритм; отдельная ветка и регрессия. Производительность не сравнивалась, ускорение не заявляется.

## 2026-11-03 — различать формат каталога и формат CFRA

Реальный luindex подтверждает исправление только после согласованного импорта меток. Храним явный mapping и отдельно результаты raw/adapted. Неправильный ответ upstream не служит performance baseline; скорость сравнивать только на корректных постановках.

## 2026-11-03 — предупреждение вместо запрета пустого множества индексов

Отсутствие индексированных рёбер может быть допустимо; печатаем объяснение в stderr и сохраняем вычисление, включая epsilon-ответы. Диагностика не доказывает несовместимость и не обнаруживает частичный неверный импорт.

## 2026-11-03 — первый performance baseline только корректной версии

CPU incremental/luindex, последовательные новые процессы, прогрев + пять повторов. Все ответы проверены; raw и агрегаты сохранены. Профилированные времена и исходная неверная версия не смешиваются с baseline.

## 2026-11-03 — приоритет CPU-эксперимента по профилю

Основное sampled user CPU time в cuBool, accumulated MxM включает существенную долю объединений. Следующий эксперимент — измерить частоту пустых результатов/целей, прежде чем менять backend. Это не доказанный избыточный вызов и не вывод о GPU. Для WSL проверен прямой perf с software events, изменения ядра/sysctl не потребовались.

## 2026-11-03 — испытывать CPU fast path вне baseline

Счётчики подтвердили 98% accumulated unions с пустым участником. Отдельная библиотека с двумя короткими ветками прошла проверки и дала 1.606× на incremental/luindex. Не применяем к основному клону до расширенной проверки; GPU-эффект не заявляется. Сравнение проведено без инструментирования, baseline измерен заново в чередующейся серии.

## 2026-11-03 — GPU корректность важнее замеров

GPU-only сборка исключает скрытый CPU fallback. Внешняя серия остановлена после воспроизведения ошибок примитивов; GPU performance не измеряем до исправления. Разность и MxM рассматриваем как разные проблемы. Исправление empty-right difference изолировано в отдельной библиотеке, исходная сохранена. Установка CUDA использует WSL repo SDK-компоненты без Linux display driver.

## 2026-11-04 — отдельный основной репозиторий

По выбору пользователя ведём cfpq-gpu-research как единый репозиторий материалов и переносимых патчей. CFRA сохраняет локальную Git-историю; коммиты экспортируются через format-patch, что позволяет восстановить код без второго remote. Личная расшифровка не публикуется. При отправке upstream PR можно позднее создать fork. Опытные CPU/GPU патчи остаются изолированными.

## 2026-11-06 — перенос исходников в основной репозиторий

Исходники CFRA, cuBool и GoogleTest теперь отслеживаются обычными файлами в src/cfra, с сохранёнными лицензиями и SHA в SOURCE_ORIGINS. Git-метаданные прежнего клона сохранены локально. Исторические patches не применять повторно. Обновление cuBool взято из явно указанного fork vano105/cuBool, PR19; это отдельный шаг после коммита переноса. Старые результаты не переименовываются в результаты новой версии.
