## Первичные источники

1. NVIDIA, Using CUDA Warp-Level Primitives: https://developer.nvidia.com/blog/using-cuda-warp-level-primitives/ — __activemask показывает текущую сходимость потоков; она не гарантирует требуемую группу для суммирования. Краткая синхронизация перед activemask также не гарантирует, что потоки останутся сведёнными.
2. NVIDIA CUDA Programming Guide, C++ Language Extensions: https://docs.nvidia.com/cuda/cuda-programming-guide/05-appendices/cpp-language-extensions.html — участники shuffle должны вызывать операцию с согласованной маской; чтение из неучаствующего потока не определено. width должен быть степенью двойки.
3. NVIDIA CUDA Programming Guide, Cooperative Groups: https://docs.nvidia.com/cuda/cuda-programming-guide/04-special-topics/cooperative-groups.html — создание partition является коллективной операцией всех потоков родительской группы.
4. NVIDIA Compute Sanitizer: https://docs.nvidia.com/compute-sanitizer/ComputeSanitizer/index.html — memcheck проверяет доступы к памяти, racecheck общую память, synccheck синхронизацию. Эти инструменты не заменяют сравнение математического ответа.

Источники прочитаны2026-11-06. Требования сопоставлены с локальными исходниками; самостоятельные выводы и подтверждённые пробы разделены в таблице.
