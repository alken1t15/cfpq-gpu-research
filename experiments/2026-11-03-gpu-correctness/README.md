# Первичная корректность GPU CFRA

Дата: 2026-11-03. Статус: корректность НЕ пройдена; серия остановлена агентом после воспроизведения базовых ошибок примитивов. Это не performance baseline.

## Воспроизведение

```powershell
wsl -d Ubuntu -- python3 /mnt/d/semen_task_avtomat/scripts/check-gpu-catalog.py
```

Скрипт читает подготовленные входы предыдущей CPU-серии: ../2026-11-03-trial-catalog/inputs.json. Их URL/контрольные суммы/размеры и mapping хранятся там. Планировалось 6 графов × 3 алгоритма, таймаут180с. Фактически сохранено 14 результатов; оставшиеся4 (luindex lazy и gson три алгоритма) намеренно не запускались дальше после провала корректности. Не трактовать их как успешные/таймауты.

GPU-библиотека исходного cuBool без CPU trial-патча и без GPU-патчей, CFRA содержит прежнее исправление парсера. Отдельная Release CUDA12.4-сборка с arch86, CPU fallback OFF. cuBool_GetDeviceCaps подтвердил CUDA на RTX3060 Laptop, устройство/хеши manifest.json. Неправильные ответы не связаны с незаметным fallback. Времена этой серии не используются для заявлений о скорости.

## Изоляция

Полные ответы маленьких матриц проверены отдельно в ../2026-11-03-gpu-setup/: CPU24/24, GPU22/24 для distinct output. Изолированы неверная разность с пустым правым аргументом и неверное умножение. Отдельная расширенная проба MxM выявила также различие при алиасинге вывода/входа (592/864 прошли). Поддержку всех alias-режимов следует сверять с API-контрактом отдельно; nonalias арифметический контрпример не зависит от этого вопроса.

Следующий шаг — исправлять примитивы по одному с минимальными регрессиями, сохраняя эту baseline-библиотеку. CPU-оптимизация не считается исправлением CUDA.
