# Расширение сравнения FLPQ

Добавлены девять графов с локальными архивами и опубликованным числом пар. Вместе с предыдущими семью это 16 графов из восьми категорий. Новая категория name_resolution представлена jiaozi и jsonpath. Для остальных семи категорий добавлено по одному входу.

Серия использует CFL_adv -t -efbl на CPU и CFRA incremental с кешем на CUDA. По пять измерений после прогрева. Сводка сравнивает полное время процесса после сверки эталона и хешей входов. Запуски последовательные, ошибки сохраняются по этапам.

После замеров очередь снимает CPU-профили airflow и luindex, а также CUDA-профиль airflow. Для luindex уже сохранена CUDA-трасса с кешем. В ней cudaStreamSynchronize занял суммарно 41,31 с по длительности вызовов API и вызван 1 406 538 раз. Это профильная метрика, её нельзя напрямую вычитать из медианы времени обычных запусков. Сопоставление профилей ещё ожидается.

Команда из корня репозитория: bash experiments/2026-11-27-flpq-expanded/run.sh. Локальные результаты находятся в data/flpq-all/flpq-expanded-2026-11-27.

## Результаты расширения

CPU завершил 45 из 45 замеров с эталоном, GPU завершила пять пар на восьми из девяти графов. GPU быстрее на django (0,667 против 0,921 с), CPU быстрее на остальных семи сопоставимых графах. На jsonpath прогрев GPU без кеша превысил 900 с; CPU вернул 59 764 пары с медианой 19,813 с. Вместе с исходной серией доступны 14 прямых сравнений из 16, из них три в пользу GPU. Для apache нет результата CPU, для jsonpath нет результата GPU.

Меньший по числу рёбер luindex создаёт намного больше матричных операций после раскрытия правил. Порядок величины затрат подтверждается числом CUDA-вызовов. Длительности API могут перекрываться с GPU и относятся к профилированным запускам. По этой таблице нельзя разложить разницу полного времени CPU/GPU на отдельные причины.

CFL_adv напечатал собственное время 0,4100 с на airflow и 0,2947 с на luindex в прогонах под perf. Профиль всего процесса на airflow содержит 1099 отсчётов пользовательского CPU-времени, два неразрешённых адреса libgomp дают суммарно 49,04%. На luindex 177 отсчётов, крупнейший символ GB_quicksort_2_32_32 даёт 17,51%. Профили охватывают загрузку и анализ; по неразрешённым адресам нельзя определить, выполнялись ли ожидание, планирование или обработка данных. Для точной детализации CPU требуется отделить загрузку от анализа.

## Диагностика jsonpath

`python3 scripts/trial-store-column-blocks.py --case-list experiments/2026-11-27-flpq-expanded/cases.csv --graph jsonpath --compare-cache --progress --timeout 120 --out data/flpq-all/jsonpath-progress`

Добавлены метки начала и конца итераций в изолированный CFRA. Вход содержит 185 421 вершину, 5 138 меток, 322 976 рёбер и 5 619 бинарных правил после раскрытия.

Прогон без кеша достиг начала первой итерации, но до её завершения истёк лимит 120 с. Максимальный секундный отсчёт по GPU составил 5 972 МиБ из 6 144 МиБ. Явной ошибки выделения памяти в журнале нет. Близость к пределу и отсутствие завершённой итерации сами по себе не объясняют таймаут. Следующий диагностический шаг — отметить границы операций первой итерации и записать память во время каждой фазы.
