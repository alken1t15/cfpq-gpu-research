# Пакетное чтение bin metadata: изолированный trial

Дата: 2026-11-06. База 4b24ccc, ветка research/gpu-bin-metadata. Production-исходники не изменены.

## Гипотеза и изменение

CUDA trace показал 232440 DtoH-передач по4байта в30с luindex. В count/fill host-код читает размеры и смещения bins из device_vector по одному элементу. Гипотеза: два пакетных чтения на фазу и повторное использование host-массивов сократят число API-вызовов. Это не гипотеза об ошибке математического алгоритма.

Генератор создаёт копии count_nz.h/fill_nz.h в build/gpu-bin-metadata и меняет только параметры launch helpers и передачу метаданных. После формирования bins host_vector копирует готовые bin_offset/bin_size; helper-ветви используют const host references. В count exec_block_row уже была неявная host-конверсия по значению: она заменена общей копией, а не продублирована. Device-биннинг/перестановка и kernels не меняются; host-копии расположены после Thrust binning на default stream, а не перед записью метаданных. Потоки count и явная синхронизация сохраняются. Alias/tile/row-mask не меняются.

Пересобран только cuda_matrix_multiply.cu.o с новыми include; остальные объекты из полной интеграционной сборки. Link/compile команды — build-commands.json, SHA — manifest.json, переносимый diff — metadata.patch. Исходная library SHA256 проверена до/после сборки; baseline сохранён. Сборка exit0, build.log пуст.

Старая запись ошибки сохранена в checks.json, в статистику не включена. Проверки не дублировались. Сначала исполнявшийся Python сохранил старую версию блока, хотя файл уже был исправлен — это причина отдельного перезапуска.

Все1+5 запросов на каждой библиотеке дали1356. Baseline wall median0.692618с, диапазон0.604165–1.628769; trial median0.642452с, диапазон0.594318–1.582790. Не экстраполировать результат на luindex или CPU/GPU сравнение.

## Вывод и следующий шаг

Metadata-only trial корректен на выбранных матричных и12малых внешних конфигурациях, снижает число копирований/синхронизаций на полном pizza. Устойчивое ускорение не доказано; trial не интегрируется автоматически. Следующий шаг — большой luindex с300с лимитом, затем контрольные повторы в более стабильных условиях и сравнение объёма работы/trace. Для запуска trial требуется LD_LIBRARY_PATH=build/gpu-bin-metadata и прежний CFRA, а не --cpu. Streamreuse/alias/tile остаются отдельными экспериментами. Полная GPU-корректность и причина прежнего timeout не установлены.
