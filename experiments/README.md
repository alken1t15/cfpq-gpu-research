# Эксперименты

Реальных запусков CFPQ пока нет. `TEMPLATE.md` — только шаблон.

Каждый эксперимент хранить в отдельной папке вида `YYYY-MM-DD-short-name/`: описание, команды, логи, сырые результаты, скрипт анализа и полученные графики. Не перезаписывать исходный baseline. Большие входы хранить вне Git и фиксировать ссылки и SHA256.

Минимальные поля таблицы сырых измерений: experiment_id, revision, implementation, graph, grammar, input_sha256, run, warmup, elapsed_ms, timing_scope, reachable_pairs, correctness, status. Память и число итераций добавлять при возможности с указанием метода измерения.

Схему адаптировать после изучения фактических выходов проекта. Пустое поле и «не измерено» предпочтительнее выдуманного значения. Speedup считать как время baseline / время варианта при сопоставимых условиях.
