# Минимальное исправление CUDA A\empty

Дата: 2026-11-03. Статус: воспроизведено, исправлено в отдельной опытной библиотеке; CUDA backend в целом всё ещё некорректен из-за MxM.

## Контрпример и причина

A={(0,1)}, B=empty, обе матрицы3×3, выход отдельный. Математически A\B=A. CPU выдаёт {(0,1)}, исходный GPU выдаёт empty. Фактические полные пары: ../2026-11-03-gpu-setup/primitive-cpu.json и primitive-gpu.json.

В cuda_matrix_ewisemult_inverted.cu исходный guard обнулял результат при пустом A **или** B. Это корректно для пересечения, но не для разности.

## Изменение и воспроизведение

```powershell
wsl -d Ubuntu -- python3 /mnt/d/semen_task_avtomat/scripts/trial-gpu-empty-difference.py
```

A пусто → пустой результат. B пусто → копия A, либо no-op если результат уже A. Иначе прежняя CUDA-операция. Поддержка alias-empty ветки предусмотрена кодом, но прямой тест alias этой операции пока не добавлен. Патч меняет только один guard и не меняет MxM.

Генерируется копия одного .cu с исходной лицензией, компилируется nvcc12.4 с флагами baseline и GCC11 host, линкуется отдельная libcubool.so из неизменённых объектов и новой реализации. Путь build/gpu-empty-difference. Production-клон и baseline GPU-библиотека не меняются, их хеш проверяется. Хеши и результаты manifest.json; команды commands.json, переносимый патч cubool-empty-difference.patch. Версии и среда — ../2026-11-03-gpu-setup/.

## Проверки и результат

Пробы distinct output: **23/24** вместо22/24. Все шесть примеров разности теперь совпадают с oracle. Оставшийся провал — известное nonalias MxM; он не скрывается и не считается исправленным. Полные результаты primitive-trial.json.

CFPQ atom, та же grammar nested_parentheses_subClassOf_type, incremental: **6 пар вместо0**, совпадает с каталогом. Вывод atom.stdout/atom.stderr, код0. Это причинное свидетельство влияния исправления на этот CFPQ-вход, не доказательство устранения всех ошибок алгоритма на GPU.

## Ограничения и следующий шаг

Патч пока не применён к основному cuBool, CPU fast path остаётся отдельным экспериментом. GPU корректность в целом не пройдена: нужно изолировать и исправить MxM, проверить alias/deferred-режимы разности и вернуться к внешним графам. Ускорение GPU не измерялось и не заявляется.
