# Ранний выход для пустого произведения в CUDA cuBool

База — `3075fac` с исправлениями маски и переиспользования входной матрицы. Исторический эксперимент [zero-fill](../2026-11-10-empty-fill/README.md) показал сокращение числа запусков ядер и API-вызовов. Однократное сравнение времени на luindex мотивирует повтор, но устойчивое ускорение пока не установлено.

Единственная правка алгоритма в fill_nz.h переносит существующее чтение последнего смещения CSR перед распределением строк по корзинам. Если смещение равно нулю, заполнить нечего и возвращается пустой массив столбцов. Смещения строк, размеры CSR и дальнейшее объединение с выходом сохраняются. Для ненулевого произведения выполняется прежний путь.

## Сборка и проверка

В WSL из корня репозитория:

```bash
CFRA_BUILD_DIR="$(pwd)/build/gpu-empty-fill-alias" bash scripts/build-wsl-gpu.sh
python3 scripts/check-gpu-empty-fill-alias.py
```

Исходные бинарники CUDA сверены с манифестом эксперимента gpu-alias. Новая сборка идёт в отдельный каталог. Проверка запускает тесты алиасинга, примитивов и границ умножения, затем проверяет ответ pizza/incremental. После этого обе библиотеки загружаются одним и тем же исполняемым файлом CFRA. Скрипт проверяет путь libcubool через ldd и сверяет хеши подготовленного luindex с предыдущим экспериментом.

Один прогрев на библиотеку, затем пять пар с чередованием порядка. Ответ в каждом запуске должен быть 9 677. Лимит — 900 секунд. Полное время включает запуск и завершение процесса. Замеры выполняются последовательно, без профилировщика. Журналы сборки и выполнения, SHA-256, stdout/stderr и измерения сохранены в data/flpq-all.

## Результат

Полная сборка завершилась успешно. Кандидат прошёл 864/864 проверок MxM, 138/138 граничных проверок, 24/24 проверок матричных примитивов и pizza/incremental с ответом 1356. На luindex оба прогрева и все пять чередующихся пар вернули 9677. Хеши бинарников до и после серии совпали.

Медиана полного времени исходной библиотеки — 219,165 с (213,947–226,191), кандидата — 144,788 с (125,730–155,366). Кандидат быстрее во всех пяти парах. Отношение медиан — 1,514, сокращение времени — 33,9%. Результат относится к luindex/incremental в этой серии. Журналы и все повторы сохранены в data/flpq-all/gpu-empty-fill-alias.
