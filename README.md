# CFPQ GPU Research

Исследование корректности и производительности GPU-алгоритма контекстно-свободной достижимости (CFPQ) на основе [CFRA](https://github.com/vano105/cfra).

## Результаты

- Исправлено раскрытие индексированных шаблонов грамматики. На luindex после адаптации меток ответ изменился с 7472 на эталонные 9677 пар во всех трёх алгоритмах. [Протокол](experiments/2026-11-03-java/README.md).
- Изолированная CPU-оптимизация accumulated MxM дала 1.606× на incremental/luindex. Результат относится только к этой конфигурации. [Измерения и ограничения](experiments/2026-11-03-empty-union-trial/README.md).
- GPU-сборка работает, но обнаружены ошибки матричной разности и умножения. Общая GPU-корректность ещё не достигнута, замеры GPU-производительности отложены. [Ошибки](docs/BUGS.md), [GPU-протокол](experiments/2026-11-03-gpu-correctness/README.md).

## Восстановление исходников

Все исходники CFRA, cuBool и GoogleTest уже включены в репозиторий. Достаточно обычного git clone. [Происхождение и версии](docs/SOURCE_ORIGINS.md).

CPU-сборка и штатные проверки: `wsl -d Ubuntu -- bash /mnt/d/semen_task_avtomat/scripts/wsl-cpu-smoke.sh`. GPU-сборка: scripts/build-wsl-gpu.sh. Скрипты экспериментов пока используют локальный путь `/mnt/d/semen_task_avtomat`; при размещении в другом каталоге его требуется адаптировать. Окружение, версии и фактические команды сохранены в протоколах experiments/.
